# III Torneo Nacional de Debate · NNGG España — DEMO

Versión actualizada de la maqueta web con el formato real comunicado:

- Debate académico (no British Parliamentary).
- Logo NNGG visible en cabecera y portada.
- 27 de septiembre: cierre de inscripciones.
- 3 o 10 de octubre: fase clasificatoria en 13 ciudades.
- 24 de octubre: gran final en Madrid con 16 equipos.
- Sesiones de formación y temas elegidos por votación.

Los equipos, ciudades asignadas, resultados y porcentajes de voto de esta demo son ficticios salvo las fechas y datos generales facilitados para el torneo.

## Ejecutar

```bash
npm install
npm run dev
```
